# Rust + WASM + React Test Project

This is a basic testing project to demonstrate using a Rust library crate compiled to WebAssembly (WASM) in a React project.

---

## Project Structure

- `my_lib/` – A Rust library crate that contains the core Rust code.
- `idmap-test/` – A React project that consumes the WASM output from the Rust crate.
